# Explanations Go Linear: Interpretable and Individual Latent Encoding for Post-hoc Explainability
Code and data for running [ILLUME](https://arxiv.org/abs/2504.20667). The code has been tested with Python 3.8.12.

To run the method, please look at [main.ipynb](illume/main.ipynb) for data loading, model training, and explanation inference.
